## Descripción del proyecto

Este proyecto consiste en desarrollar el clásico
juego del ahorcado utilizando Python.

El jugador deberá adivinar una palabra oculta,
ingresando letras hasta descubrirla o perder
sus 6 vidas.

## Cómo ejecutar el programa

1. Abrir la carpeta del proyecto en Visual Studio Code.
2. Abrir la terminal.
3. Ejecutar el siguiente comando:

python3 main.py

> [!NOTE]
> El juego se ejecuta desde la consola y fue desarrollado en Python.
